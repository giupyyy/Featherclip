# Featherclip

Tiny background clipper for Windows. Press a hotkey and the last seconds of your screen and sound are saved as a video.

## Download

1. Open **Releases** and download **Featherclip-Windows.zip**.
2. Unzip it and start **Featherclip.exe**.
3. Right-click the red dot in the tray (bottom right) and choose **Settings**.

Default hotkey: `Ctrl+Alt+F9`, but can be customized
